# Search Space

- Complete set of all possible states that can be reached while trying to solve a problem
- It represents
	- All possible configurations
	- All possible paths from start to goal
	- All possible solutions (valid or invalid)

# State Space

- Mathematical model of all possible states of a problem
- It includes
	- Initial state
	- Intermediate state
	- Goal state

# Search Space vs State Space

| Search Space                   | State Space                           |
| ------------------------------ | ------------------------------------- |
| All possible exploration paths | All possible **VALID** configurations |
| Includes paths + states        | Only states                           |
| Used during search             | Used for modelling problems           |

> [!note]
> The actual definitions seem somewhat ambiguous, and the terms are even used interchangeably.
